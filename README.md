## Run locally
1. Open this folder in VS Code.
2. Install/use Live Server.
3. Right-click `index.html`.
4. Choose "Open with Live Server".

## Main functionality
- Responsive dark-blue visual theme inspired by the supplied reference screenshots.
- Shared header/footer generated from one JavaScript file, so changing navigation/footer is done once.
- Mobile navigation.
- Portfolio category filters.
- Animated homepage counters.
- Scroll reveal effects.
- Enquiry form validation.
- Latest enquiry saved to browser localStorage.
- Enquiry can be sent to WhatsApp after submission.
- Direct WhatsApp and email contact buttons.
- FAQ accordion using native details/summary.
- Service detail pages and pricing page.
- Privacy/terms starter pages.

## Important
The portfolio/testimonial pages intentionally avoid fabricated client claims. Replace placeholder portfolio examples and testimonial placeholders with real, verified projects/feedback.

The pricing values are starting references and should be adjusted to your actual commercial pricing before publishing.
